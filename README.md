# 剧西西 · 西语追剧学西语

通过热门西语影视剧台词学西班牙语：双语字幕、跟读、刻意练习、场景词汇闪卡与理解测验。

支持 **移动端 Web**（可打包 iOS/Android APK）、**手表**、**智能眼镜 / 麦克风 / 耳机**，以及戒指/手杖手势。

## 功能

| 模式 | 说明 |
|------|------|
| **剧目** | 浏览 6 部经典西语剧，选场景开始学习 |
| **追剧** | 逐句台词：西/中字幕、TTS 朗读、连播、本地视频同步 |
| **练习** | 沉浸式剧场、影子跟读、弱项重练、填空/复述、TPR 手势、SRS 统计 |
| **闪卡** | 从台词提炼的 28 个高频词，间隔重复（SRS） |
| **测验** | 每场景理解题，巩固剧情与词汇 |

### 练习模式（学习机制）

| 机制 | 说明 |
|------|------|
| **沉浸式剧场** | 隐藏导航，全屏专注当前台词 |
| **影子跟读** | TTS 示范 → 麦克风跟读 → ✅/⚠️ 即时反馈，漏读词高亮 |
| **弱项重练** | 按失败率/SRS 到期排队难句，通过才跳下一句 |
| **主动输出** | 关键词填空、看中译复述西语 |
| **TPR 全身反应** | 台词关键词映射戒指/手杖手势（如 tap=进入） |
| **间隔重复** | 台词 + 词汇双轨 SRS；跟读通过/失败自动打分 |
| **统计面板** | 待练台词、待复习词、连续学习天数、每句练习次数 |

### 智能设备

| 设备 | 能力 |
|------|------|
| 👓 **智能眼镜** | 窄屏自动启用；语音口令翻句、朗读、跟读、切换模式 |

## 快速开始

```bash
cd active/juxixi
npm install
npm test
npm run build
npm start          # http://localhost:5182
```

### 练习流程

1. **剧目** → 选剧 → 选场景
2. 切到 **练习** 标签
3. 选子模式：**影子跟读** / **弱项重练** / **填空** / **复述**
4. 点 **开始跟读**（或戒指下倾 / 手杖敲击）→ 先听后说
5. 查看 ✅/⚠️ 反馈与高亮漏读词；弱项模式需通过才跳下一句
6. 开启 **沉浸剧场** 可隐藏干扰，专注单句

## 本地视频

在「追剧」模式点击 **导入视频**，选择你拥有的影视剧文件；字幕行会按时间轴自动高亮同步（需自备合法片源）。

## 移动端打包

```bash
npx cap add android    # 首次
npm run sync:android
npm run apk:debug
```

修改 `index.html` 或 `src/` 后先 `npm run build`，再 `npx cap sync`。

```
  catalog.test.js
  learning.test.js
```
